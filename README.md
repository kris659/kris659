# Payout - Shop Simulator

[Steam Page](https://store.steampowered.com/app/3551680/Payout__Shop_Simulator/)

A shop simulator that I have been developing for over two years. I lead the project and handle nearly all programming as well as most of the game design. Early development included collaboration on game and map design, and the project is currently supported by another contributor assisting with development.

Key systems and features I implemented include:

- Vehicle physics and driving mechanics
- Employee AI systems
- Robust building system
- Full UI implementation with localization support
